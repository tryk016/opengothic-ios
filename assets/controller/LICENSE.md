# Controller prompt assets

The controller and keyboard prompt images in this directory are derived from
**Xelu's Free Controller & Keyboard Prompts** by Nicolae "Xelu" Berbece:

https://thoseawesomeguys.com/prompts/

The original asset pack is dedicated to the public domain under
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).

OpenGothic-specific composition and layout files in this directory remain
covered by the repository's main license unless a file states otherwise.
